# Smart India Hackathon (SIH 2026)
## Adaptive Path Planning and Collision Avoidance on Unstructured Indian Roads

This repository contains the software prototype and core logic validation for our autonomous vehicle navigation system designed specifically for unpredictable Indian road conditions.

### 🚀 Key Features
- **Sensor Fusion Logic:** Simulates a 500m macro-detection warning system combined with low-latency onboard sensor tracking.
- **Dynamic Obstacle Avoidance:** Real-time path recalculation when detecting unpredictable obstacles like potholes, debris, or cattle.
- **Adaptive Trajectory Recovery:** Smoothly returns the vehicle to the optimal center path once the obstacle is cleared.

### 🛠️ Tech Stack & Setup
- Language: Python 3.x
- Libraries: `matplotlib`, `numpy`

To run the simulation locally:
```bash
pip install matplotlib numpy
python simulation.py
```
